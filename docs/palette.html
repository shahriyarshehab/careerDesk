How the plate is applied

Four gradients cover every interactive and progress surface

Primary action linear-gradient(135deg, var(--cdp-cta-from), var(--cdp-cta-to))
Selected / active brand-600 → brand-700 · white label
Break / pause warning-500 → warning-600
Destructive danger-500 → danger-600
Progress ring ring-start → ring-end (Cyan 400)
Focus / hover tint color-mix(brand-500 16%, transparent)
